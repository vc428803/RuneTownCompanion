# RuneTown Companion

RuneTown Companion 是一個使用 **Java 21** 開發的領域模型原型，目前定位為 **Nexelyth 的人生進程系統（Life Progression）原型**。

> **你不是因為反覆刷取而成長，
> 而是因為真正生活過而成長。**

---

## 專案方向

Nexelyth 不希望把現實人生做成：

```text
工作 / 讀書 / 運動
        ↓
      經驗值
        ↓
       升級
```

而是：

```text
真實人生事件
      ↓
有意義的成長證據
      ↓
      收藏
      ↓
  路徑 / 身份
      ↓
   角色成長
```

核心原則：

> **成長來自證據，而不是刷取。**

---

## 人生進程 vs 戰鬥進程

```text
                    Nexelyth
                       │
          ┌────────────┴────────────┐
          │                         │
       人生進程                  戰鬥進程
          │                         │
       現實人生                  VR 世界
          │                         │
   你正在成為誰                你如何戰鬥
```
